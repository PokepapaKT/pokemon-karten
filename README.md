# Kartenbinder

Web-App zum Scannen, Sammeln und Bewerten von Pokémon-Karten (Deutsch, Englisch, Japanisch).

- **Öffnen:** https://pokepapakt.github.io/pokemon-karten/
- **Aufs iPhone/iPad legen:** Link in Safari öffnen → Teilen-Knopf → „Zum Home-Bildschirm“.
- **Kartendaten und Preise:** [TCGdex](https://tcgdex.dev) mit Preisen von Cardmarket (EUR) und TCGplayer (USD).
- **Scannen:** Texterkennung im Browser mit [Tesseract.js](https://tesseract.projectnaptha.com/). Gelesen werden Kartenname und Kartennummer (z. B. 025/165).
- **Speicher:** Die Sammlung liegt nur auf deinem Gerät. Über „Sicherung speichern“ kannst du sie als Datei sichern.
